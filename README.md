# CyberNative Games — closed

CyberNative Games closed on 29 September 2026. This repository no longer accepts game submissions. New pull requests are not reviewed, play-tested or merged.

The submission guide ([`CONTRIBUTING.md`](CONTRIBUTING.md)), the manifest schema ([`game-manifest.schema.json`](game-manifest.schema.json)) and the sample in [`submissions/`](submissions/) stay here as a record.
